2) INNER JOIN - COMMON VALUES FROM BOTH THE VALUES (USED WITH COMPARISION, WHERE) - WHAT ABOUT NULL VALUES

4) RIGHT JOIN - RIGHT TABLE ALL VALUES & MATCHING VALUES FROM THE MATCHING TABLE (NULL VALUES WILL BE THERE)
5) FULL OUTE JOIN - LEFT + RIGHT JOIN BOTH TOGETHER
6) UNION & UNION ALL - COMBINED ROWS (UNION WILL REMOVE DUPLICATES, UNION ALL WILL INCLUDE DUPLICATES)
7) CROSS JOIN - COMBINATION OF BOTH TABLES
8) SELF JOIN - WE WILL USE LEFT, RIGHT, FULL JOIN IN THEM ALSO
9) EXAMPLES OF JOINS - TABLE CREATION AND JOINS IN DETAIL EXPLANATION
